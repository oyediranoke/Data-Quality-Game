# Data Quality Challenge Game

This is an interactive HTML-based classroom game for a Business Intelligence course.

Students answer data quality scenario questions and receive instant feedback. At the end of the game, their score is submitted to a Google Sheet, and a live leaderboard is displayed inside the game.

## Features

- 25 Data Quality questions
- Instant feedback after each question
- Final score display
- Answer review section
- Automatic score submission
- Google Sheet score tracking
- Live leaderboard embedded from Google Sheets
- Suitable for classroom activity or self-practice

## Data Quality Dimensions Covered

- Accuracy
- Completeness
- Consistency
- Timeliness
- Validity
- Uniqueness
- Relevance

## Technologies Used

- HTML
- CSS
- JavaScript
- Google Apps Script
- Google Sheets
- GitHub Pages

## How It Works

1. Student opens the game link.
2. Student enters their name.
3. Student answers all questions.
4. Score is automatically submitted to Google Sheets.
5. The leaderboard updates from the published Google Sheet.

## Deployment

The game is deployed using GitHub Pages.

The Google Sheet and Apps Script are not stored in this repository. They remain hosted in Google Drive and are connected through URLs inside the HTML file.

## Notes

If the leaderboard does not load for a student, they should refresh the page or open the game in Incognito/Private mode.
